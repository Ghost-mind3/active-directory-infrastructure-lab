# Active Directory Security Lab

Ce projet est un **laboratoire Active Directory pratique** conçu pour s’entraîner à l’administration système et aux concepts de base en sécurité.

Il montre comment déployer un domaine, organiser les utilisateurs et les machines, et appliquer des politiques de sécurité via les Group Policy Objects (GPO).

---

# 🎯 Objectifs du projet

Ce laboratoire a été créé pour pratiquer :

- Le déploiement d’Active Directory
- La structure des unités d’organisation (OU)
- La gestion des utilisateurs et des groupes
- La configuration des stratégies de groupe (GPO)
- La gestion des accès privilégiés
- Windows LAPS
- Les bases de l’audit de sécurité
